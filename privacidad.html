Política de privacidad

Última actualización: octubre de 2026.

Responsable y contacto

ESV Media es un proyecto personal de creación y experimentación audiovisual y digital. Para consultas relacionadas con privacidad puedes escribir a esvmedia1@gmail.com.

Datos personales

Este sitio web informativo no solicita directamente datos personales mediante formularios ni crea cuentas de usuario. Si contactas por correo electrónico, los datos que facilites se utilizarán únicamente para atender tu comunicación.

Servicios de terceros

El sitio puede incluir enlaces a servicios o plataformas externas. El tratamiento de datos realizado por dichos servicios se rige por sus propias políticas de privacidad.

Conservación y derechos

Las comunicaciones se conservarán únicamente durante el tiempo necesario para atenderlas o cumplir las obligaciones aplicables. Puedes solicitar información, rectificación o supresión de tus datos escribiendo al correo de contacto indicado.

Cambios

Esta política podrá actualizarse si cambian las funcionalidades del sitio o los servicios utilizados.
